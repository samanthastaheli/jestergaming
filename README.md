# jestergaming

Gesture controller for Stardew Valley! (only available for Windows)

# Setup

First, git clone the repository

Create a conda environment (you can also use a virtual environment).

`conda create -n jester python=3.10`

Activate your conda environment

`conda activate jester`

Install the requirements

`pip install -r requirements.txt`

# Playing Stardew Valley

Make sure Stardew Valley is already running on half the screen. 

Then, in a terminal with the conda environment activated, run the following command:

`python run_live_stream.py`

In the startup menu, when you hit "s" to start the game, make sure to click on your Stardew Valley window so that the program can find it. 

You should be good to go from there! 

Video Example: https://youtu.be/R_jDBKFpT8Y

# Tips

For best results, make sure to have good lighting and a non-busy background. The program doesn't do well with multiple hands in the camera, so make sure no one is standing behind you!
